# New Look Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plain, professional office look: neutral grey with one blue accent, dark and light mode, system font,
line icons drawn for this project instead of emojis, and less wasted space. No third-party code.

**Architecture:** Every colour in `app.css` becomes a CSS custom property, with a light set and a dark set. The server
writes `data-theme` on `<html>` from a whitelisted `theme` cookie (through a context processor), and a sidebar toggle
sets that cookie and `localStorage`. Icons come from one inline SVG sprite (`templates/sheet/icons.svg`, a Django
include) and a `dom.js` `icon(name)` helper that only points at known `#i-…` symbols. Source-file tests keep emoji,
Google hosts and stray hex colours out.

**Tech Stack:** Django 5.2 templates, plain CSS, vanilla ES modules, jsdom (dom_test, smoke test).

**Spec:** `docs/superpowers/specs/2026-11-18-new-look-design.md`

## Global Constraints

- Branch `feature/new-look` from `main`, built in a git worktree under `.superpowers/worktrees/`. Merge only when the
  user agrees.
- Look B tokens:
  - Dark: `--bg #141517`, `--surface #1c1e21`, `--surface2 #232529`, `--line #2c2f34`, `--text #e8e9eb`,
    `--muted #9a9ea6`, `--accent #4c8dff`.
  - Light: `--bg #f6f7f8`, `--surface #fff`, `--line #e1e3e6`, `--text #1b1d20`, `--muted #646a73`,
    `--accent #2563eb`.
  - Plus `--surface2` for light, and `--danger` / `--warning` / `--success` per mode. All text meets WCAG AA (4.5:1)
    on its surface.
- Font stack: `"Segoe UI", system-ui, -apple-system, Roboto, sans-serif`. No Google Fonts anywhere.
- CSP:
  - `style-src` / `style-src-elem` become `'self'`, and `font-src` becomes `'none'`.
  - Nothing else changes. No new sources.
- Icon style: 24×24 viewBox, `fill="none"`, `stroke="currentColor"`, stroke-width 1.75, round caps and joins.
  - Drawn for this project. The mockup `.superpowers/brainstorm/2028-1794955044/content/look-b-dark.html` already has
    paths for anchor, ship, import, bed, car, calc, chart, db, swap, clock, bell, trash, menu, plus, key, out, alert,
    sun and down. Reuse them.
- `h()` stays HTML-only. `icon()` uses `createElementNS` and only ever sets `href="#i-<known name>"`.
- No `innerHTML`, no inline `style=`, no Trusted Types policy. `npm run check` stays green. LF line endings.
- Lean screens: no new help text. Decorative-only text goes ("Click for details →"); text that carries
  information stays.

## Review Focus

- **A bad theme cookie** (`theme=red`, `theme=<b>x</b>`, a very long value) → no `data-theme` attribute, and the page
  follows the system setting. Task 1 test.
- **`localStorage` blocked** (private window) → the toggle still switches and the cookie still sets, with no JS
  error. Task 1: the smoke step runs with storage throwing.
- **Printing** a vessel summary from dark mode → prints dark text on white (`@media print` forces the light
  tokens). Task 3 test on `app.css`.
- **Pages without the app's JS** (login, password change, locked, 404, 500) → no Google request, themed by the cookie
  or the system. 404 and 500 have no request context, so they follow the system only. Task 1 tests.
- **Light mode legibility** of danger text, warning text, the "(no agent)" row and the chart colours on white. Task 3:
  a contrast check in the test on the token values.

**Files:**

    icons gets `{% include "sheet/icons.svg" %}` right after `<body>`.

    calculations, history, rates, render/dashboard, list, notifications.

**Interfaces:**
- Consumes: Task 1 tokens (icons use `currentColor`).
- Produces:

      swap, clock, key, log-out, bell, trash, pencil, plus, x, check, alert, menu, sun, moon, chevron-down,
      chevron-up, sort, arrow-right, calendar, users, printer, globe, settings, plus any the build needs.
    - `export function icon(name, cls = '') -> SVGSVGElement`: builds `<svg class="ic [cls]" aria-hidden="true"

  - CSS `.ic{width:16px;height:16px;flex-shrink:0;vertical-align:-3px}`.
